# Authored marker contract fixtures

These six response files are entirely synthetic, created for notebook 02. They are
not EIA captures or measured Colorado electricity sales. The CO/RES-shaped identifiers
exercise the real released worker's documented route, facet and legacy-ID interfaces.

The six monthly source values are `"0"`, `"12.5"`, `"w"`, `null`, `"*"`, and `"18"`.
The real worker interprets their statuses and numbers. Both explicit-route and
legacy-series pages contain identical authored rows. The server checks exact paths,
queries, a dummy credential and file hashes; it performs no analysis or paging logic.
The metadata and two-entry sector dictionary are also explicitly synthetic.

Only three months are numeric, including numeric zero. Their sum 30.5 is an
available-month subtotal, never a complete six-month estimate. The notebook changes
a minimum-observed-month requirement from 3 to 4 without changing these source rows.
